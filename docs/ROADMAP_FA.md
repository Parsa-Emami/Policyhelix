# رودمپ متن‌باز PolicyHelix

هدف، سورس کامل Apache-2.0 و اجرای محلی بدون حساب پولی/ابری، دامنهٔ عمومی یا کلون پروژهٔ دیگر است. `npm run setup` و `npm start` اکنون موتور واقعی Go را همراه با ذخیره‌سازی محلی پایدار، بستهٔ سیاست امضاشده و سرویس بالادستی ساختگیِ تحت مالکیت اجرا می‌کنند. گردش‌کار کامل شش‌مرحله‌ای، حالت‌های منفی، ری‌استارت و بازیابی در C30 تأیید شده است؛ پروفایل local-demo از نشست‌های ساختگیِ موتور (مقید به اثر انگشت و قابل ابطال) استفاده می‌کند و گواهی امنیتی تولیدی نیست. پیش‌نمایش JSON بخشی از فضای کاری است، نه موتور تخصصی.

در plans/commits برای هر C01 تا C40 یک کارت با مسیر فایل‌ها، گام‌های دقیق، پیش‌نیاز، منابع، سخت‌افزار، دادهٔ آزمایشی و مجوز، حالت خطا، فرمان آزمون، شواهد و بازگشت وجود دارد. فرمان‌های وابسته به موتور آینده صریحاً علامت خورده‌اند.

- C01–C06: قرارداد استفاده، نسخه‌های قفل‌شده، موتور واقعی، قرارداد داده، ذخیره‌سازی و CI.
- C07–C26: بیست قابلیت تخصصی همین پروژه همراه آزمون و اتصال واقعی وب.
- C27–C30: امنیت، ظرفیت اندازه‌گیری‌شده، سلامت موتور، نصب از کلون، انجام کار اصلی و بازیابی. **C30 نخستین نقطهٔ قابل بهره‌برداری محلی است** و با شواهد واقعی تأیید شده است.
- C31–C38: بستهٔ کامل موتور/وب و سورس، مجوزها، نصب/میزبانی اختیاری، UX، مستندات، ارتقا و تکرار مستقل نصب و رفع موانع.
- C39–C40 (تأییدشده). کنترل شواهد انتشار و نصب نسخهٔ عمومی. [نسخهٔ v1.0.0](https://github.com/Parsa-Emami/Policyhelix/releases/tag/v1.0.0)

ایجنت از AGENTS.md و قرارداد اجرا شروع می‌کند و با `npm run plan -- next` کار بعدی را می‌گیرد. هیچ آزمون اجرا‌نشده یا قابلیت ناقصی انجام‌شده ثبت نمی‌شود. محدودیت دائمی schema دیتابیس، migration، .env و Dockerfile برقرار است.
